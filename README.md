## Если телефон скрыт в Telegram

Скрытый в профиле номер может встретиться в старой записи, где он был связан с аккаунтом. Бот не открывает текущие приватные настройки Telegram. Он ищет сохранённые сведения, доступные для запроса. Если связь нашлась, номер можно проверить отдельно и увидеть дополнительные записи того периода.

История юзернеймов тоже бывает полезна. Допустим, человек сменил ник, а старое имя осталось в других сервисах. По прежнему нику можно попробовать поискать связанные аккаунты. Дата записи, если она есть, поможет понять, когда использовалось это имя. Для подарков и упоминаний в чатах логика похожая: это дополнительные зацепки об аккаунте, но не готовая биография человека.

Если ник виден только на скриншоте, перепишите его точно, включая цифры и подчёркивания. Когда имени пользователя нет, но известен ID, используйте его.

## Как перейти из Telegram к другим соцсетям

Представим, что по `@username` появился номер. Проверка номера может показать почту или профиль ВКонтакте. По ссылке либо ID ВКонтакте можно сделать ещё один запрос и увидеть связанные поля из доступных записей. Если вместо номера появился прежний ник, попробуйте его в поиске по поддерживаемой соцсети. Некоторые люди используют похожие имена на разных площадках, а записи помогают найти контакт, который связывает эти профили.

Если известен только телефон, начните с него. В ответе может быть Telegram-ник, включая прежний. Проверьте найденный аккаунт по нику или ID.

Когда обычного поиска мало, в боте есть глубокий поиск по поддерживаемым параметрам. Его отчёт может собрать больше контактов и связанных записей. Это отдельная платная функция; условия и доступные типы запросов смотрите перед запуском. В старых данных встречаются уже неиспользуемые номера и ники, поэтому при чтении отчёта полезно учитывать даты.

## Частые вопросы

### Можно ли начать пробив Telegram без номера телефона?

Да. Подойдут точный `@username` или числовой ID. Номер может стать следующим запросом, если он появится в ответе.

### Можно ли по Telegram найти другие соцсети?

Если запись по аккаунту содержит телефон, почту или прежний ник, проверьте это поле отдельно. По нему иногда находятся профили на других площадках.

### Чем ID отличается от ника?

Ник пользователь может менять. ID служит числовым идентификатором аккаунта и помогает искать, когда старое имя пользователя уже не подходит.

Работайте со своими данными, с согласия человека или при другом правомерном основании. Не пересылайте чужие контакты и отчёты в открытые чаты.
